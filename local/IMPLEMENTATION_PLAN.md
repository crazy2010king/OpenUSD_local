# OpenUSD示例程序梳理与移植 - 实现规划与设计文档

## 项目背景
本项目是对OpenUSD官方示例程序的系统性梳理、移植和封装，目标是降低OpenUSD的学习门槛，提供开箱即用的示例集合和配套工具。

## 整体架构设计

### 目录结构设计
```
local/
├── docs/                    # 文档目录
│   ├── usd_examples_guide.md    # 示例程序详细说明文档
│   └── images/                  # 文档配图（预留）
├── examples/                 # 移植后的示例程序
│   ├── core/                     # 核心USD功能示例
│   ├── imaging/                  # 渲染成像相关示例
│   ├── physics/                  # 物理引擎相关示例
│   └── exec/                     # 执行框架相关示例
├── scripts/                  # 工具脚本目录
│   ├── build_examples.sh          # 一键编译构建脚本
│   ├── run_all_examples.sh        # 统一调度运行脚本（交互式）
│   └── test_examples.py           # 自动化测试验证脚本
├── README.md                 # 项目快速入门说明
└── IMPLEMENTATION_PLAN.md    # 本规划设计文档
```

### 设计原则
1. **独立性**：所有示例均可独立编译运行，不依赖整个USD工程的构建系统
2. **易用性**：提供统一的入口脚本，降低使用门槛
3. **可扩展性**：目录结构清晰，方便后续添加更多示例
4. **可测试性**：内置自动化测试脚本，可快速验证所有示例的可用性

## 功能模块设计

### 1. 示例分类体系
根据功能特性将示例分为四大类：
- **exec执行框架**：USD计算执行框架相关示例，用于学习程序化计算流水线
- **core核心USD**：USD基础功能、自定义扩展、文件格式插件等核心能力示例
- **imaging成像渲染**：Hydra渲染框架相关示例，用于学习渲染器开发
- **physics物理引擎**：USD物理模拟相关示例，用于学习物理场景构建

### 2. 编译构建脚本
- 自动检测USD安装路径
- 支持增量编译
- 按分类并行编译示例
- 统一输出到build目录，不污染源码目录

### 3. 统一运行脚本
- 交互式菜单设计，方便用户选择
- 自动设置环境变量（PATH, LD_LIBRARY_PATH, PXR_PLUGINPATH_NAME）
- 支持按分类运行、单独运行、全量运行三种模式
- 运行后自动展示效果说明

### 4. 测试验证脚本
- 自动检测依赖完整性
- 自动编译、运行示例
- 验证输出结果正确性
- 生成可视化测试报告
- 支持批量测试和单独测试

## 平台适配说明

### 支持平台
- 硬件：Intel/AMD x86_64 架构 + NVIDIA GPU (可选)
- 系统：Ubuntu 22.04 LTS / 20.04 LTS
- 依赖：GCC 9+, Python 3.8+, OpenUSD 23.08+

### 兼容性处理
- 所有不兼容当前平台的示例（需要额外依赖或仅支持特定系统）均在文档中明确标注，暂不移植
- 保留官方示例的原始代码结构，仅修改CMake配置以支持独立编译
- 针对Ubuntu平台做了路径和环境变量适配
